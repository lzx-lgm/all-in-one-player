连接向导 借鉴 Mineradio 的连接原理 · 本站不在本站输入任何平台密码

1 · 选平台
选一个音乐源，右侧列表会立刻清空旧内容、显示骨架屏，再加载新源——不出现新标题配旧内容。
2 · 官方扫码登录
打开官方登录页扫码（网易云 / QQ / 酷狗 / 汽水扫码，QQ 可选 QQ 或微信扫码）。播放器只是一个窗口，凭证 Cookie 只留在官方页面与本机。

3 · 同步我的收藏
在官方页完成登录后回这里确认，只同步你已收藏的专辑 / 艺人 / 歌单，不翻全站目录。桌面版用内嵌登录窗真同步官网歌单；网页版读不到官网 Cookie，确认后只作本机标记，刷新后标记会重置。

连接原理与音乐源端点表（八个源共用同一套抽象）

· 播放换源：非 Apple 源走应用内播放链路；Spotify 官方不提供音频直链、汽水付费歌常只给试听——遇到试听 / VIP 时，6 秒内并行去其它已登录平台按「歌名 + 艺人 + 时长」匹配同一首歌自动换源，找不到就保留试听并明示。
· 歌词与音乐源分离：歌词走 QQ → 酷狗 → 网易云独立回退链，歌词卡右上角会标出实际命中的来源。
· 本地兜底：不登录任何平台，也能导入本地音频 / 视频按原始格式、原始分辨率播放。

平台中心 状态如实显示 · 不假装已连接
